## 总览

**minclass 求解器**（`tools/csp_export/minclass_solver.py`）：以「最少类数」为目标的
一次性 CSP 求解。解空间由**类 + 指针 + 数组 + 基元类型共同张成**（用户裁决，2026-11-03），
证据族 25+ 个，全部约束经冲突台账自动消解，确定性双跑验证。

| 指标 | 弧起点 | 当前 | 增幅 |
|------|------:|------:|-----:|
| 严格层唯一解（100% sound） | 10,169 | **20,800** | +105% |
| 启发式层唯一解（方向性参考） | 11,008 | **25,579** | +132% |
| 受约束簇（严格） | 16,738 | 44,138 | +164% |
| K_min（最少类型数） | 573 | 735 | — |

口径：唯一解 = 候选域收敛到单元素的簇 / 受约束簇总数。严格层判据全部为二进制
必要条件；启发式层附加弱证据（冲突由台账自动丢弃弱侧）。

## 证据族清单（现行 25 族）

### 二进制身份（严格）
- **C4/C6**：构造函数 vtable 装表 → 类身份 + 槽位数
- **C2/C16**：this 传递 / 参数传递（实参域 ⊑ 形参域）
- **C1**：成员访问（偏移×宽度 → 候选类必须有兼容成员）
- **C3/C30**：虚调用接收者（主表/次级表）
- **C19**：dtor 集 / SSA 栈槽生命周期分裂

### 执行流（严格，ffl4-ffl6 引擎族）
- **FS**：赋值物化等值——每个槽存/成员存都是物理等值边（S↔S 2,134 / M→S 921 / RET→S 61…）
- **RI**：返回身份——构造返回 this（RET≡T 1,877）、getter（M→RET 894）、转发器（RET→RET 499）
- **VB**：接收者锚定虚拟调用绑定（4,045 站点，含 66 别名类桥接）
- **GS**：override 签名结构一致性（同槽 paramK = 继承族内同一逻辑变量，95.5% 组内验证）

### 成员/接收者类型（严格）
- **MT**：`??_7` 虚表安装 → 按值成员直钉（912）
- **MR**：接收者域 × member_types 槽类型（7,703，两遍法）
- **MD**：成员二进制事实反钉接收者（判别器）

### 编译器签名（严格，2026-11 新方向）
- **IT/IV**：指令语义值类型——`movzx/movsx`（u8/i8/u16/i16）+ FPU `fld/fstp`（float/double），
  全基址实体解析（this/参数/全局 pointee），**指令语义 = 编译器亲手写下的类型声明**（2,012）
- **SP/MS**：字符串字面量实参/返回 → char*（二进制字节验证）
- 权威表校准：954 类已穷尽二进制全部 RTTI vtable（954/954 回放四项全对）

### 启发式层附加
- **MRH**（放宽成员类型并集 4,475）、**IR**（全常量返回→int 族 2,960）、
  **CP**（全常量实参→int 族 703）、**FS**（格式串位 40）、**MH**（跳表枚举 36）、**CS**（指针步进尺寸）
- 启发式层语义 = 严格证据 + 无可靠证据反驳的合理缺省（反例类逐一记录在案）

- 双跑 SHA256 确定性验证（每轮）
- YRpp 只读审计（113 in-domain / EXCLUDED 0）——从未进入证据侧
